A smaller change to Work

  • Batches sit in their existing column, outside “No topic.” Ordinary topic groups remain.
  • Children open in Work, with a route back to their batch.
  • One task status and one preview message appear first. The full status breakdown is expandable.
  • Reported work uses plain text, never a completion bar.
  • Mobile keeps status tabs and a single detail view.

The default snapshot is based on the UI audit. Alternate demo states illustrate proposed behavior, not live task status. Nothing is posted or changed on the protocol.
